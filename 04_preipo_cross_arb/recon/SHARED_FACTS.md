## 2. 对冲配平关系（代码硬编码基准）
```
ASSUMED_SHARES_B = 12.7          # 假定完全稀释股本 127 亿股
TARGET_OKX = -q_HL * (10.0 / 12.7) = -q_HL * 0.787401...
RESIDUAL   = TARGET_OKX - q_OKX
```
- `RESIDUAL ≈ 0` → 已对冲
- `RESIDUAL > 0` → **OKX 相对目标偏空过头（需 BUY OKX 买回超额）**
- `RESIDUAL < 0` → **OKX 相对目标欠对冲（需 SELL OKX 补空）**

> ⚠️ **本文件早期版本这两行写反了（曾写作「RESIDUAL<0 → 需买回」），已按公式与 §3 实盘动作更正。**
> 判据：`RESIDUAL = TARGET_OKX − q_OKX`，买入会让 `q_OKX` 增大逼近 `TARGET`，所以**买回必须对应 RESIDUAL > 0**。
> §3 的实盘动作也印证：`RESIDUAL = +1.8585 → 买入 1.8585`。
> 若照旧版文字实现，会把每一次修正的方向取反，误差不是「不修」，而是「修成两倍偏差」。
